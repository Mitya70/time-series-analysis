# Данные

| Файл | Описание | Источник |
|---|---|---|
| `international-airline-passengers.csv` | Число авиапассажиров, тыс., месячные данные 1949–1960 (144 точки) | Time Series Data Library (R. Hyndman) |
| `mean-monthly-air-temperature-deg.csv` | Среднемесячная температура, °F, 1920–1939 (240 точек) | Time Series Data Library |
| `monthly-boston-armed-robberies-j.csv` | Вооружённые ограбления в Бостоне, месячные, 1966–1975 (118 точек) | Time Series Data Library |
| `monthly-sales-of-company-x-jan-6.csv` | Продажи компании X, месячные, 1965–1971 (77 точек) | Time Series Data Library |
| `daily-total-female-births-in-cal.csv` | Рождения девочек в Калифорнии, дневные, 1959 (365 точек) | Time Series Data Library |
| `weekly-closings-of-the-dowjones-.csv` | Недельные закрытия индекса Dow Jones, 1971–1974 (162 точки) | Time Series Data Library |
| `motionsense_jog_9_sub_21.csv` | Сенсоры iPhone (DeviceMotion, 50 Гц): бег, сессия `jog_9`, участник 21 | [MotionSense](https://github.com/mmalekzadeh/motion-sense), файл `A_DeviceMotion_data/jog_9/sub_21.csv` |

Классические ряды TSDL — общедоступные учебные датасеты (в копиях, распространявшихся через DataMarket и учебные материалы курса).
